# Article catalog

Store public metadata and language mapping here; do not store article body text.

Create articles.json after source reconnaissance. Each record should include a stable ID, source URL, English title, course and section, English and Vietnamese relative paths, section order, discovery time, source hash when available, and language status.

Allowed statuses: discovered, fetched, extracted, translated, reviewed, source-changed, blocked.

Do not guess totals or mark work complete before verification. Track crawl notes and permission findings in PROGRESS.md.
